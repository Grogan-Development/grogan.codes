One graph, every workflow

Everything reads the same revision.

Browsing, review, CI and AI all ask the same graph about the same commit, so a review comment, a failing test and an answer in chat agree about what the code does.

01

Source

Plain git over HTTPS, stored in S3. Protected refs only move through an atomic compare-and-swap, so 50 parallel pushes give exactly one winner.

02

Change requests

Revisions, range diffs, comments that follow the code, stacks and a merge queue. Approvals survive a clean rebase and reset on a real change.

03

Code graph

Definitions, calls, references and impact for Rust, TypeScript, Python and Go, from compiler indexes where possible and inference where not.

04

Build

Steps are cached by their inputs, so an unchanged commit finishes in seconds. Jobs run in throwaway micro-VMs with no access to your secrets unless you allow it.

05

Spaces

A cloud dev machine per repo that hibernates when you stop typing and resumes where you left off. Connect from the CLI or VS Code.

06

Ask, review, fix

Ask questions, get advisory reviews, triage red builds and hand a failure to an agent that opens a change request. AI never approves or merges.

Answers you can check

Exact when it knows. Labelled when it doesn't.

Results from a compiler index are marked exact. Results the graph inferred are marked cand and ranked below them. Every line inlines its source, so you and your agent spend fewer tokens opening files to confirm.

  • Citations are checked against the graph before they're shown.
  • Answers name the revision they were computed at.
  • Queries have time and memory budgets, and say when they're truncated.
